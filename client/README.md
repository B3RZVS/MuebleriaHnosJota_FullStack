# Client de Mueblería Hermanos Jota

Hecho con React, TypeScript y Vite. La instalación, las variables de entorno y el deploy están en el [README principal](../README.md).

| Comando           | Qué hace                                     |
| ----------------- | -------------------------------------------- |
| `npm run dev`     | Levanta el client en http://localhost:5173   |
| `npm run build`   | Chequea tipos y genera el build en `dist`    |
| `npm run preview` | Sirve localmente el build generado           |
| `npm run lint`    | Ejecuta ESLint                               |
| `npm run format`  | Ordena el código con Prettier                |
